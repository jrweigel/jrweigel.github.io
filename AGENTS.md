## Europe 2026 Travel Guide

## Source of truth

- static/Europe2026/index.html is the mobile travel guide source.
- Confirmed TripIt reservations must be clearly distinguished from tentative plans.

## Required behavior

- Preserve all Google Maps links and official website links.
- Keep the HTML optimized for mobile use.
- Never change confirmed dates, times, addresses, transportation, or reservations without explicit instructions.
- Clearly mark unbooked restaurants and activities as planned or suggested.
- Flag conflicts rather than guessing.
- Check links and validate HTML before finishing.

## Publishing

- Make changes on a branch.
- Open a pull request.
- Do not push directly to main.
- GitHub Pages publishes after the pull request is merged.
